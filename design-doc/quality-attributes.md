# Атрибуты качества

- Немецкий без ошибок; у каждой строки перевод.
- Кадр «было | стало» для любой правки, которую называют исправленной.
- Кнопки ≥ 48 px, текст читается на телефоне.
- Переход между сценами ≤ 300 мс, без перезагрузки.
- Работает без микрофона и без сети после первой загрузки.
- Ни одного ассета без записанной лицензии.
