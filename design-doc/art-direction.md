# Арт-дирекшн

- Пиксель-арт, сетка 32 px, вид сверху 3/4, тёплый уютный свет («HD-2D лайт»).
- Одна палитра и одна обводка на всё: чужие паки перекрашиваются под `docs/ui_kit.css`.
- Персонажи двух видов: чиби и нормальные пропорции. Герой: тёмно-синяя куртка (ждёт подтверждения).
- UI: дерево и бумага, пиксельная рамка. Шрифты: Pixelify Sans, VT323.
- Генерация ИИ только для уникального (Elternhaus). Персонажи и пропсы — из бесплатных паков.
- Анти-референсы: реализм, неон, коллажи из разных стилей.
