# Концепт

**Жанр:** уютная RPG-деревня + учебник немецкого. Пиксель-арт, 32 px, вид сверху 3/4.
**Платформа:** браузер (PWA), телефон и ПК.

## Фантазия игрока
Ты переехал в Германию и не можешь сказать ни слова. В мире языка лежит деревня Stillbach, которую съела тишина
(Verstummen). Каждое немецкое слово, сказанное вслух, возвращает ей кусок жизни: дом, колодец, соседа, песню.

## Герой и мир
- **Герой:** {hero_name} (пока Max), 23, новичок в саксонской деревне. Учит язык с нуля.
- **Brezel:** бордер-колли, спутник и подсказчик.
- **Herr Schmidt:** сосед, первый собеседник.
- **Тишина:** не злодей, а забытые слова. Главный конфликт: переводчик-приложение «Dolmi», которое
  обещает «не учить язык», и его создатель Viktor Brandt.

## Цикл (3–10 минут)
Двор → тап по дому (зум) → урок прямо в сцене с NPC → фраза вслух = заклинание → награда появляется во дворе.

## Столпы
1. **Мир = интерфейс.** Нет отдельных экранов-меню: урок идёт в сцене.
2. **Слово меняет мир.** Прогресс виден глазами: деревня отстраивается.
3. **Говорить, а не зубрить.** Речь, слух, повторения FSRS вместо таблиц.
4. **Уют.** Без штрафов и таймеров.

## Рост
Мир открывается по главам: A1 = свой дом и двор, A2 = деревня, B1 = совет общины, B2 = хроника,
C1 = голос деревни. После C1 — бесконечная песочница-империя.

## Не делаем
Соревновательный рейтинг, донат, рекламу, откровенный контент, текст чужих учебников в репозитории.
